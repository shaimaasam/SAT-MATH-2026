# SAT Math 2026 - Interactive Workbook

A professional SAT Math preparation platform with interactive lessons, quizzes, and step-by-step solutions. Built with Next.js 16, TypeScript, Tailwind CSS, and KaTeX.

## Features
- 4 Chapters with 25+ lessons
- 94 SAT Math questions with full solutions
- 41 Desmos graphing calculator hints
- Quiz Center with 12-min timer and 5-min cooldown
- Flashcards for active recall
- Question of the Day
- Achievements system
- Dark/Light mode
- LaTeX math rendering (KaTeX)
- localStorage progress persistence

## Tech Stack
- Next.js 16 (App Router, Turbopack)
- TypeScript 5
- Tailwind CSS 4
- shadcn/ui (Radix UI)
- KaTeX for LaTeX rendering
- Prisma ORM
- next-themes for dark mode

## Getting Started
\`\`\`bash
bun install
bun run dev
\`\`\`

Open http://localhost:3000
